The game reaches the main menu, and once you start a game, the emulator crashes after a few seconds.

## Steps to reproduce

1. Open KytyPS5.
2. Boot the game.
3. Enter the main menu.
4. Start a new game.
5. Play for a few seconds if you can.

## Expected behavior

Game Crash

## Extra notes

The game was working using an older version of the emulator, but I can't remember which one, and it was playable around 8 to 10 fps.
