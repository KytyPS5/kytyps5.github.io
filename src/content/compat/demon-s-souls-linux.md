The game boots past the logos and opening cutscene fine. The language selection and screen calibration fully work, and the main menu as well as the settings menu are controllable. After hitting new game, the game crashes within about 10 seconds, though it should be noted that if the user selects a body type fast enough, they can reach the character customization screen and the default character renders.

## Steps to reproduce

1. Open KytyPS5 2026-09-16-63fb822
2. Launch the game
3. Proceed with setup and display calibration, and then start a new game

## Expected behavior

The game should proceed to the character customization menu.
