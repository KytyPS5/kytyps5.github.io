The game does not boot. KytyPS5 starts loading the game, but it does not reach the first logo, startup screen, or main menu.

## Steps to reproduce

1. Start KytyPS5.
2. Select The Persistence Enhanced Edition (PPSA01916).
3. Launch the game.
4. Wait for the game to initialize.
5. The game does not reach the first logo or startup screen.

## Expected behavior

The game should boot and reach the startup logo / main menu.
