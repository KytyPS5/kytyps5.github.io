The game boots successfully and reaches the main menu. After selecting New Game, the opening cinematic plays normally. When the cinematic finishes, the game closes/crashes before gameplay begins.

## Steps to reproduce

1. Start KytyPS5.
2. Launch Unbound: Worlds Apart (PPSA03274).
3. Select New Game.
4. Wait for the opening cinematic to finish.
5. The game closes/crashes immediately after the cinematic.

## Expected behavior

The game should continue into gameplay after the opening cinematic.
