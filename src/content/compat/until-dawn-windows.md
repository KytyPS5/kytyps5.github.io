Game boots to the main menu. Can start a new game and the cutscene plays, then goes in game and can be played.

Very low frame rate, no audio and some minor graphical issues.

## Steps to reproduce

1. Open Translator
2. Boot Game
3. Start New Game.

## Expected behavior

Game boots, starts and goes in game, as expected.

## Extra notes

Default settings. There is audio up until the main menu, it is gone after that.
