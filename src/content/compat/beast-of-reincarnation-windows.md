The game boots, but the initial logos and intro sequences are not displayed. The screen remains black, with no visible response to clicks or input. The game then freezes and crashes.

## Steps to reproduce

1. Open KytyPS5.
2. Boot the game.

## Expected behavior

1. Open KytyPS5.
2. Boot the game.
3. Logos and intro sequences should display correctly without graphical corruption, missing textures, or crashes.
4. The main menu and other UMGs should render correctly and remain fully interactive.
5. The game should proceed into playable gameplay normally, with graphics and UI displaying as expected.
