Horizon Forbidden West boots and reaches the main menu. The startup sequence and menu visuals appear to work well. Audio is laggy and stutters. The game crashes when I try to proceed past the main menu, so I have not reached gameplay.

## Steps to reproduce

1. Start KytyPS5 and boot Horizon Forbidden West.
2. Wait for the main menu.
3. Try to start new game
4. Observe the crash

## Expected behavior

Selecting New Game should load the game without crashing, and audio should play smoothly.
