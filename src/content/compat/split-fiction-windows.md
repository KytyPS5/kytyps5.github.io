The game starts and shows the logo. After a few seconds, the license agreement and the main menu appear.

I don't have a second controller and couldn't even launch the main game. I doubt it would even run anyway, since the main menu is lagging at 1 fps.

You need to enable "Windows SysV red zone crash protection" for the license agreement and main menu to appear.

## Steps to reproduce

1. Open KytyPS5
2. Enable Windows SysV red zone crash protection
3. Launch the game
4. Wait for the license agreement and accept it
