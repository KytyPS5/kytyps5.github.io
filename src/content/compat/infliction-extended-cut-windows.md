The game boots and reaches the logo screen, but then freezes. It does not progress past the logo screen or reach the main menu.

## Steps to reproduce

1. Start KytyPS5.
2. Select Infliction: Extended Cut (PPSA02688).
3. Launch the game.
4. Wait for the game to reach the logo screen.
5. The game freezes on the logo screen and does not continue.

## Expected behavior

The game should continue past the logo screen and reach the main menu.
