The game boots and displays the initial logo screens, but then freezes and does not progress any further. It does not reach the main menu.

## Steps to reproduce

1. Start KytyPS5.
2. Select Ys X Proud Nordics (PPSA32457).
3. Launch the game.
4. Wait for the initial logo screens to appear.
5. After the logos, the game freezes and does not continue.

## Expected behavior

The game should continue past the logo screens and reach the main menu.
