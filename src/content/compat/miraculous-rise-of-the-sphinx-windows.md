The game runs very well, with a few frame drops in certain areas (to be more exact areas with lots of objects loaded in). Still, there aren't any glitches or issues present and the audio is perfect.

## Steps to reproduce

1. Open KytyPS5
2. Boot Game 
3. New Game

## Expected behavior

When entering any kind of menu (such as the pause or teleportation menus) the game should be blurred. However the game goes to a black screen while this is happening in the emulator. This also applies if there are objectives that pop on the screen which need to be confirmed by pressing the O button
