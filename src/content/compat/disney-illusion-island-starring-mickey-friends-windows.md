1. Launch KytyPS5.
2. Select and launch the game.
3. Wait for the game to finish loading.

The game should boot, display its menus, and run gameplay correctly without noticeable issues.

## Extra notes

Since this game works perfectly, I would like to suggest adding a dedicated page to the KytyPS5 project that lists games and their compatibility status.

This page would make it easier for users to see which games work, which ones are partially working, and which ones have not yet been tested. It would also help the community contribute compatibility reports and avoid repeatedly testing games that are already known to work.

Suggested status categories:

Works perfectly: The game boots and runs normally, with no noticeable issues.
In game: Playable gameplay is reached, but some issues may remain.
Main menu: The game reaches the main menu but cannot yet enter gameplay.
Logo / Booting: The game displays a startup logo but does not reach the main menu.
Not working: The game fails to boot or encounters a blocking issue.
Not yet tested: No compatibility results have been reported.
Partially working: The game runs, but significant bugs or limitations affect the experience.

It would be especially useful if each game entry included the game title, game ID, tested KytyPS5 build, compatibility status, known issues, and community-submitted reports or screenshots.

A searchable and filterable page, potentially organized as a compatibility database or wiki, would help users quickly find games that work perfectly and understand the current state of emulation. It could also encourage community participation by allowing users to submit new results and update existing entries as KytyPS5 improves.
