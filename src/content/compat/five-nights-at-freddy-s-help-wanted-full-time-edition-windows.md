The game runs very well, with a few frame drops in certain areas. Highest it runs is between 50fps and 60fps and lowest was between 20fps and 30fps. Audio plays okay and in correct order and achievements unlock just fine.

## Steps to reproduce

1. Open KytyPS5
2. Boot Game 
3. New Game

## Expected behavior

In FNAF 1's levels and the Game Over screen the outline that shows up when an object can be picked up remains stuck to the camera. Before any object outline shows up the level's cameras has an unusual outline, but it doesn't affect gameplay. Specific to the Game Over screen, if an object was picked during the level when you get killed, its outline will show in the Game Over room.

In FNAF 1 and FNAF 2 levels when you pause the game there will be a loud noise present which stops when one of the options available in the menu gets pressed (such as restarting or quiting the level, where you then need to confirm your choice).
