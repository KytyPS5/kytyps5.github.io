The game boots successfully, reaches the main menu, and enters playable gameplay. Performance is stable and no FPS-related problems were observed.

However, several issues are present:

- Loading times appear unusually long in some sections.
- There seems to be an input/controller issue. Some button inputs do not behave as expected or are difficult to understand during gameplay.
- Subtitles and some interface text do not appear correctly.
- No audio can be heard.
- The displayed language appears inconsistent, with some text in English and some text in Japanese.

Despite these issues, the game reaches gameplay and continues running without major performance problems.

## Steps to reproduce

1. Start KytyPS5.
2. Launch Memories Off Sousou: Break out of my shell.
3. Wait for the game to reach the main menu.
4. Start a new game or continue into gameplay.
5. Observe the unusually long loading times in some sections.
6. Test the controls and button inputs during gameplay.
7. Observe that subtitles and some interface text are missing.
8. Observe that no audio is played.
9. Observe that the displayed language is partially English and partially Japanese.

The game remains running and reaches playable gameplay with stable performance.

## Expected behavior

The game should load normally, all controller/button inputs should function correctly, subtitles and interface text should display properly, audio should play normally, and the selected language should be displayed consistently throughout the game.
