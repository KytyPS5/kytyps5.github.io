It loads perfectly but when the game tries to load a save or a new game, it’ll get stuck at the loading screen for the game.

## Steps to reproduce

Open KYTYPS5 launcher
Open the Watch Dogs Game in mini menu
Go to campaign (only option available)
Create new game
Load game
It’ll get stuck there.

## Expected behavior

Once you get to the loading screen, it should freeze after loading up past 70 percent of the load.
