The game boots and reaches the initial logo screen, but then closes/crashes shortly afterward. It does not reach the main menu.

## Steps to reproduce

1. Start KytyPS5.
2. Select Total Chaos (PPSA32393).
3. Launch the game.
4. Wait for the initial logo screen.
5. After the logo, the game closes/crashes and does not continue.

## Expected behavior

The game should continue past the logo screen and reach the main menu.
