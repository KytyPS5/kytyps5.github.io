Game boots into a "Menu" if you could call it that that says press any button to start. When you click start it has a high rate of crashing right away but rarely makes it to the main menu for a few seconds. (Only one time did it get to the point where you can start the actual gameplay but crashed in the menu)

## Steps to reproduce

1. Open KytyPs5
2. Open Teardown
3. Click any button to start the game
4. It either crashes right away or crashes in next menu
5. May have to click start in second campaign menu

## Expected behavior

Crash

Vblank Frequency: 60 fps
Resolution: 720p
