# Running kitten

Original artwork generated with the built-in image-generation tool, then packaged into a transparent, two-color GIF palette (teal plus transparency). No third-party stock asset is used. The sprite sheet is a build source; it is not downloaded by the website.

The shared `.kitty-loader-art` CSS in `index.html` tints both exported assets blue in light mode and icy blue in dark mode, including startup before JavaScript loads. The original artwork, frame timing and transparency are preserved.

Run `npm run generate:kitty` to reproduce the GIF and static reduced-motion PNG. Twelve frames, 80ms each, 960ms per loop. A common scale, nose anchor and foot baseline align the frames.

## Generation prompt

Use case: stylized-concept. Asset: animation sprite sheet for a tiny website loading GIF. Create a perfectly regular 4-column by 3-row sprite sheet, TWELVE frames total, on a genuinely transparent background. Every cell has identical dimensions and ample padding; no cell borders, no labels, no text. Exactly ONE small kitty per cell. Same adorable smooth solid forest-teal (#073f3b) kitten in every frame, strict side view facing right, consistent size, center and anatomy. Premium simple flat silhouette: compact softly rounded bean-shaped torso, round head, two small rounded triangular cat ears, tiny snout, short plush legs, and a thick gently curved upright tail. One tiny negative-space eye is enough. Single flat solid color throughout, no outlines, no shading, no texture, no accessories, no speed lines, no ground or shadows. Make it charming and unmistakably a kitten, with soft, elegantly flowing contours, not an angular doodle or stick figure. The 12 cells in row-major order depict successive evenly spaced phases of one seamless gentle running/trotting-in-place cycle. Four little legs move naturally in alternating pairs, small vertical body bounce, subtle tail movement. Keep the face, body, head, and tail design consistent. Camera locked, kitten stays centered within each cell; feet baseline consistent. High clarity at 100px displayed width. This is production animation artwork to be cropped into twelve equal-sized frames; obey the 4 by 3 equal-cell layout exactly.
